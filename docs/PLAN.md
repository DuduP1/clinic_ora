# תוכנית בנייה – CRM קליניקת אורה

הבנייה מתבצעת בשלבים לפי ה-PRD. בסוף כל שלב מתבצע commit, וההיסטוריה ב-GitHub מתעדת את הגרסאות.

| # | שלב | תוצר | מצב |
|---|---|---|---|
| 1 | שלד הפרויקט | Next.js 16, עברית ו-RTL, גופן Heebo, `CLAUDE.md`, `.env.example` | ✅ |
| 2 | מסד נתונים | migration: טבלאות, enums, טריגרים, נרמול טלפון, RLS, פונקציות RPC. seed: מחירון | ⏳ |
| 3 | התחברות | Supabase Auth, `proxy.ts`, מסך כניסה, משתמשות דמו (מנהלת וצוות) | ⏳ |
| 4 | מעטפת וניווט | Layout עם תפריט צד (מחשב) וסרגל תחתון (נייד), חיפוש מהיר לפי טלפון | ⏳ |
| 5 | לקוחות | רשימה, חיפוש, יצירה, עריכה, כרטיס לקוחה עם תור הבא, היסטוריה ופניות | ⏳ |
| 6 | תורים | רשימה ומסננים, יצירה ועריכה, פעולות מהירות (בוצע / בוטל) | ⏳ |
| 7 | פניות שירות | רשימה ומסננים, יצירה ועריכה, שיוך, חוק "בטיפול מחייב אחראית", הדגשת 24 שעות | ⏳ |
| 8 | מסך ראשי | מונים, טבלת פניות לפי אחראית, תורים היום | ⏳ |
| 9 | ניהול צוות | הוספה, תפקיד והשבתה (admin בלבד) | ⏳ |
| 10 | API לסוכן | `POST /api/agent/tickets`, `GET /api/agent/next-appointment`, אימות `x-api-key` | ⏳ |
| 11 | פריסה ובדיקה | Vercel ומשתני סביבה, בדיקה מקצה לקצה במחשב ובנייד | ⏳ |

## בדיקות בסוף כל שלב
- `npm run lint` ו-`npm run build` עוברים.
- בדיקה ידנית בדפדפן של מה שנבנה בשלב.
- נתונים נשמרים גם אחרי רענון.
